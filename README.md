# 📄 PDF Verification Using Playwright

This project demonstrates how to automate **PDF validation** using Playwright and Node.js. It specific test like 'invoice number' from the PDF.

---

## 🚀 Features

- 📥 PDF download from web applications  
- 🔍 Extract text content from PDF files  
- ✅ Validate important fields
- 🌐 Cross-browser support (Chromium, Firefox, WebKit)  
- 🧪 Integration with Playwright test framework  

---

## 🛠️ Tech Stack

- Playwright – End-to-end browser automation  
- Node.js – Runtime environment  
- pdf-parse – PDF content extraction  
- JavaScript / TypeScript
